🐧 Unix/Linux Demo Web Server

Welcome to the Demo Environment

This web server is part of the Unix/Linux demonstration environment. It's running in a Docker container and serves as a target for network utility demonstrations.

Available Network Commands

You can test these commands from the main demo container:

curl http://web-server/
wget http://web-server/
ping web-server

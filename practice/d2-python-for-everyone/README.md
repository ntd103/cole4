Tạo `compose.yml` với image `jupyter/pyspark-notebook:latest` và mount thư mục hiện tại vào `/home/jovyan/work`.

`JUPYTER_ENABLE_LAB` nghĩa là bật Jupyter Lab thay vì Jupyter Notebook.
Jupyter Lab khác với Jupyter Notebook ở chỗ nó có giao diện người dùng hiện đại hơn, hỗ trợ nhiều tab, và tích hợp nhiều công cụ hơn.

## Đọc compose.yml

Danh sách các services trong file `docker-compose.yml`:
- namenode: quản lý metadata của HDFS
- datanode1, datanode2: lưu trữ dữ liệu của HDFS
- python-client

Danh sách các ports:
- 9870: port web UI của namenode, xem tình trạng cụm
- 8020: HDFS api



>Hadoop đọc các file cấu hình core-site.xml và hdfs-site.xml
